# Mizan ميزان

**The fair price for tokenized stocks on BNB Chain, and a halal basket agent that buys at it.**

NVDA exists on BSC as three different tokens: Ondo `NVDAon`, Binance `NVDAB` and Backed `NVDAx`. Their prices, liquidity and off-hours behaviour differ. Mizan measures those differences continuously (the integrity index). Its agent buys a Shariah-screened basket through whichever wrapper is fairest right now.
